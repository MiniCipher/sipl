## [1.0.0] - 2026-11-18

Перший стабільний реліз модуля «Аналізатор семантики та інфраструктура тестування».

### Added
- **CORE-01** Формальна граматика `grammar/sipl.ebnf` (ISO-EBNF), опис лексики
  `grammar/LEXICAL.md`, корпус з 13 коректних і 16 некоректних програм; генеричний
  EBNF-розпізнавач `sipl.ebnf` та тест узгодженості граматики з парсером
  (у т.ч. на 300 випадково згенерованих реченнях граматики).
- **CORE-02** Лексер і парсер рекурсивного спуску: дерево виводу (CST) → власне типізоване
  AST (`sipl.ast`) з `SourceSpan` у кожному вузлі; діагностики з кодом, рядком/колонкою,
  підсвіченням фрагмента та підказкою (зайва `;`, `=` замість `:=`, `if` без `else`,
  незакритий `begin`, ...).
- **CORE-06** Conformance suite: 54 кейси (`conformance/cases`) з очікуваним AST,
  семантичним термом, кінцевими станами, невизначеністю та позиціями помилок;
  незалежний від реалізації runner (`conformance/run_conformance.py`, лише stdlib),
  протокол адаптера `sipl analyze` і JSON Schema формату кейсів.
- **SEM-01** Рекурсивна побудова семантичного терму з AST у нотації курсу
  (`AS^x`, `•`, `IF`, `WH`, `id`, `x⇒`, `n̄`, `S²`, `S¹`), вивід у Unicode / ASCII / LaTeX,
  пояснення кроків побудови `⟦·⟧`, golden-тести на всіх прикладах.
- **SEM-02** Обчислення терму на стані: кінцевий стан або ⊥ (незв'язана змінна, ділення на
  нуль, невизначена умова, ліміт кроків) з повним трейсом застосованих правил
  (`AS`, `SEQ`, `IF-T/F`, `WH-T/F`, `ID`, `DEN`, `CONST`, `ARITH`, `REL`, `AND`, `OR`, `NOT`)
  і ланцюжком переходів станів; сильна логіка Кліні для `∧`/`∨`.
- **SEM-03** Інтерактивний HTML-візуалізатор `sipl visualize`: код → дерево виводу → AST →
  терм → переходи станів; вибір елемента на будь-якому рівні синхронно підсвічує
  відповідні елементи на інших; покрокове програвання трейсу.
- **VIS-01** Дерево синтаксичного виводу у форматах text / JSON / DOT / SVG / HTML,
  вузли пов'язані з фрагментами коду (позиції, тексти, tooltip); компактний режим.
- CLI `sipl`: `check`, `parse`, `tree`, `term`, `eval`, `visualize`, `analyze`, `grammar`
  зі стабільними кодами завершення (0/1/2/3) і JSON-режимами.
- **REL-01** GitHub Actions: ruff, mypy, pytest з покриттям ≥ 90 % (Linux Python 3.10–3.13,
  Windows, macOS), conformance suite, збірка та перевірка wheel у чистому середовищі.
- **REL-02** Release workflow: тег `vX.Y.Z` → перевірка версії, тести, збірка sdist/wheel,
  демо-візуалізації, release notes з цього CHANGELOG.
