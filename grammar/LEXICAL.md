# Лексика SIPL

Лексичний аналізатор (`src/sipl/lexer.py`) перетворює текст на послідовність токенів.
Кожен токен має **канонічний вид** (kind), який використовується в граматиках
`sipl.ebnf` (ядро курсу) і `sipl-ext.ebnf` (розширення), та позицію у вихідному тексті
(`SourceSpan`: рядок/колонка початку і кінця, 1-based).

Альтернативні написання - це лише різні символи **того самого** термінала (підручник і
практикум самі використовують кілька варіантів: `–` і `-`, `∗` і `*`). Мову вони не змінюють.

## Ядро курсу

| Канонічний вид | Допустимі написання | Значення (функція алгебри) |
|---|---|---|
| `IDENT` | `[A-Za-z_][A-Za-z0-9_]*`, що не є ключовим словом | змінна `x` |
| `NUMBER` | `[0-9]+` | число `n`; від'ємне число - `-` перед `NUMBER` (`n ::= … –1 \| 0 \| 1 …`) |
| `begin` `end` `if` `then` `else` `while` `do` `skip` | так само (регістр важливий) | ключові слова |
| `:=` | `:=` | присвоювання |
| `;` | `;` | послідовне виконання (роздільник, **не** термінатор) |
| `(` `)` | `(` `)` | дужки |
| `+` | `+` | `add` |
| `-` | `-`, `–` (en dash), `−` (minus sign) | `sub` |
| `*` | `*`, `∗`, `×` | `mult` |
| `=` | `=` | `eq` |
| `>` | `>` | `gr` |
| `or` | `∨`, `or`, `\|\|` | `or` |
| `not` | `¬`, `not`, `!` | `neg` |

## Розширення (`sipl-ext.ebnf`)

| Канонічний вид | Допустимі написання | Функція |
|---|---|---|
| `/` | `div`, `÷`, `/` | `div` (ціла частка, округлення вниз) |
| `mod` | `mod`, `%` | `mod` (остача, `x = y·div(x,y) + mod(x,y)`) |
| `<` | `<` | `less` |
| `<=` | `<=`, `≤` | `leq` |
| `<>` | `<>`, `!=`, `≠` | `neq` |
| `>=` | `>=`, `≥` | `gre` (так у практикумі) |
| `and` | `∧`, `and`, `&&`, `&` | `and` |
| `true` `false` | так само | константи `true̅`, `false̅` |

Пробіли, табуляції та переходи рядка ігноруються.
Коментарі: `// до кінця рядка` та `{ блоковий коментар }` - не впливають на граматику.

Помилки лексики (з точною позицією): невідомий символ, `:` без `=`,
незакритий коментар `{`, ідентифікатор, що починається з цифри.
