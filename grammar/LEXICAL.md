# Лексика SIPL

Лексичний аналізатор (`src/sipl/lexer.py`) перетворює текст на послідовність токенів.
Кожен токен має **канонічний вид** (kind), який використовується в граматиці `sipl.ebnf`,
та позицію у вихідному тексті (`SourceSpan`: рядок/колонка початку і кінця, 1-based).

| Канонічний вид | Допустимі написання | Значення |
|---|---|---|
| `IDENT` | `[A-Za-z_][A-Za-z0-9_]*`, що не є ключовим словом | змінна |
| `NUMBER` | `[0-9]+` | натуральне число (константа) |
| `begin` `end` `if` `then` `else` `while` `do` `skip` | так само (регістр важливий) | ключові слова |
| `true` `false` | так само | логічні константи |
| `:=` | `:=` | присвоювання |
| `;` | `;` | послідовне виконання (роздільник, **не** термінатор) |
| `(` `)` | `(` `)` | дужки |
| `+` `-` `*` | `+`, `-` або `−`, `*` або `×` | арифметичні операції |
| `/` | `/`, `÷`, `div` | цілочисельне ділення |
| `<` `<=` `=` `<>` `>` `>=` | `<`; `<=` або `≤`; `=`; `<>`, `!=` або `≠`; `>`; `>=` або `≥` | відношення |
| `and` | `and`, `&&`, `∧`, `&` | кон'юнкція |
| `or` | `or`, `\|\|`, `∨` | диз'юнкція |
| `not` | `not`, `!`, `¬` | заперечення |

Пробіли, табуляції та переходи рядка ігноруються.
Коментарі: `// до кінця рядка` та `{ блоковий коментар }` — не впливають на граматику.

Помилки лексики (з точною позицією): невідомий символ, `:` без `=`,
незакритий коментар `{`.
